Day-1
Why Jenkins?
Configure Jenkins in Ubuntu
Create a Job in Jenkins
=============================

 - Needed for building, deploying and automating any project.
 - CICD tool.

Installation:
Take one Ubuntu machine and execute following commands:
Security Group:
	Inbound: port 22, 8080
	Outbound: All Traffic

Change hostname:
	sudo hostnamectl set-hostname jenkins-master
Logout and Login Again.

sudo apt update && sudo apt upgrade -y
sudo apt install fontconfig openjdk-21-jre -y
sudo wget -O /etc/apt/keyrings/jenkins-keyring.asc https://pkg.jenkins.io/debian-stable/jenkins.io-2026.key
echo "deb [signed-by=/etc/apt/keyrings/jenkins-keyring.asc]" https://pkg.jenkins.io/debian-stable binary/ | sudo tee /etc/apt/sources.list.d/jenkins.list > /dev/null
sudo apt update
sudo apt install jenkins -y
sudo systemctl status jenkins
ps -ef | grep jenkins
sudo systemctl start jenkins
sudo systemctl enable jenkins

Open a browser
Copy the pulic IP 
Open in browser:=> 
	public_ip:8080

Copy the password from:
	sudo cat /var/lib/jenkins/secrets/initialAdminPassword

Worker Setup:
==============
sudo hostnamectl set-hostname worker-1
sudo apt update && sudo apt upgrade -y
apt list openjdk-21*
sudo apt install openjdk-21-jdk -y
java -version

On Master machine:		
	Dashboard > Manage Jenkins > Nodes > New node
		Give a name > Node-1
		Tick Type as Permanent Agent > Click on create
		Add a description
		Number of executors 2
				To be followed:
					No. of Jobs to be executed = 2 times the no. of CPUs
		Remote root directory : /home/ubuntu/
		Labels : Empty
		Usage: Use this node as much as possible - every cicd will use this
		Launch method: Launch agents via SSH
			Host:
				PUBLIC ip OF SLAVE
			Credentials:
				Add:
					Kind: SSH Username with private key
					scope: global
					ID: Node-1
					Username: ubuntu
					Tick - Treat username as secret
					Private Key > Enter directly
						provide the private key for ssh
					Passphrase: Empty
					Add
		Host Key Verification Strategy: Non verifying Verification Strategy
		Availability: Keep this agent online as much as possible
		Save
		Built in Node: 
			Configure > Set Number of executors to 0
		Labels: Add anything
		Usage : Only build jobs with label expressions matching this node

Day-3
===================
SonarQube is an open-source platform developed by SonarSource for continuous inspection of code quality. 
Sonar does static code analysis, which provides a detailed report of bugs, code smells, vulnerabilities, code duplications.
It supports 30+ major programming languages through built-in rulesets and can also be extended with various plugins.

Setup:

Take 3 Ubuntu machines,  
	Security grp - 
		Machine			Inbound			Outbound
		Jenkins Master	22, 8080		all traffic		T3 micro, 10 GB memory.
		Node-1			22				all traffic		T3 micro, 10 GB memory.
		SonarQube		22, 9000		all traffic		T2 Medium, 12 gb

Sonar Qube set-up:
sudo hostnamectl set-hostname sonar
sudo apt update && sudo apt upgrade -y
Java is required to run sonarqube.
sudo apt install openjdk-21-jdk -y
mkdir sonarqube
cd sonarqube
sudo apt install unzip -y
wget https://binaries.sonarsource.com/Distribution/sonarqube/sonarqube-26.3.0.120487.zip
unzip sonarqube-26.3.0.120487.zip
rm -rf sonarqube-26.3.0.120487.zip
mv sonarqube-26.3.0.120487 sonarqube
cd sonarqube-26
pwd: /home/ubuntu/sonarqube/sonarqube-26/bin/linux-x86-64
Run: ./sonar.sh console
login to sonar through UI:
public_ip:9000
username and password = admin
